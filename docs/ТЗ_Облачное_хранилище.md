## 1. Введение и цели проекта

### 1.1 Описание продукта

Облачный сервис для хранения, организации и совместного использования фотографий и видеозаписей. Ключевые отличия от существующих решений (Google Photos, iCloud, Яндекс.Диск):

- **Продвинутая автоматическая индексация** — распознавание лиц, объектов, локаций, событий, настроения, цветовой палитры, технических параметров съёмки
- **Гибкая многоуровневая система доступов** — управление правами на уровне папки, альбома и отдельного файла с ролевой моделью и временными разрешениями

### 1.2 Цели проекта

- Создать удобное хранилище для личного и командного использования
- Автоматизировать рутинную работу по организации медиатеки
- Обеспечить гранулированное управление доступами для профессиональных пользователей (фотографы, студии, команды)

### 1.3 Метрики успеха

| Метрика | Целевое значение |
|---|---|
| Время загрузки страницы галереи | < 1.5 с |
| Точность распознавания лиц | > 95% |
| Точность распознавания объектов | > 90% |
| Время обработки фото после загрузки | < 30 с |
| Uptime сервиса | > 99.9% |

## 2. Целевая аудитория

### Сегмент A — Частные пользователи
Хранят личный архив, делятся фото с семьёй. Ценят автоматическую организацию и простоту.

### Сегмент B — Профессиональные фотографы
Работают с клиентами, передают галереи на согласование. Ценят гибкие доступы, быстрый просмотр RAW-файлов, водяные знаки.

### Сегмент C — Команды и студии
Несколько сотрудников работают с общей медиатекой. Ценят ролевую модель, историю изменений, совместное редактирование тегов.

### Сегмент D — Корпоративные клиенты
Маркетинговые отделы, медиаархивы. Ценят SSO, аудит-лог, интеграции с DAM-системами.

## 3. Функциональные требования

### 3.1 Загрузка и хранение файлов

#### Поддерживаемые форматы

**Фото:** JPEG, PNG, WEBP, HEIC, HEIF, TIFF, BMP, GIF, SVG  
**RAW:** CR2, CR3, NEF, ARW, ORF, RAF, DNG, RW2  
**Видео:** MP4, MOV, AVI, MKV, WEBM, M4V, 3GP  

#### Способы загрузки

- Drag & drop в веб-интерфейсе
- Выбор файлов через диалог (поддержка множественного выбора)
- Загрузка целой папки с сохранением структуры
- Мобильное приложение — автозагрузка с камеры
- Десктопный клиент — синхронизация выбранных папок
- API — для интеграций

#### Поведение при загрузке

- Дедупликация по хешу файла (предупреждение при дубликате, выбор действия: пропустить / загрузить как копию)
- Сохранение оригинала без изменений
- Параллельная загрузка до 10 файлов одновременно
- Возобновляемая загрузка при обрыве соединения
- Максимальный размер файла: 4 ГБ для видео, 500 МБ для фото

#### Хранилище

- Оригиналы хранятся без сжатия и без изменений
- Автоматическая генерация превью: thumbnail (200×200), medium (1200px), large (2560px)
- Для видео: превью-кадры каждые 10 секунд, gif-анимация из ключевых кадров

---

### 3.2 Автоматическая индексация

После загрузки каждый файл проходит очередь обработки. Пользователь видит прогресс-индикатор для статуса индексации.

#### 3.2.1 Распознавание лиц

- Обнаружение лиц на фото и кадрах видео
- Кластеризация: система группирует похожие лица и предлагает пользователю назвать человека
- После именования — автоматическая разметка на всех фото
- Возможность вручную подтвердить, отклонить или исправить атрибуцию
- Возможность полностью отключить распознавание лиц (GDPR-совместимость)
- Автоматическое обновление модели при добавлении новых фото человека

#### 3.2.2 Распознавание объектов и сцен

Система автоматически проставляет теги по следующим категориям:

| Категория | Примеры тегов |
|---|---|
| Природа | горы, море, лес, закат, снег, цветы |
| Городская среда | улица, архитектура, интерьер, кафе |
| Животные | кот, собака, птицы (с уточнением вида) |
| Люди | портрет, группа, дети, свадьба |
| Еда | пицца, суши, десерт |
| События | день рождения, вечеринка, путешествие, спорт |
| Транспорт | автомобиль, самолёт, велосипед |
| Активности | плавание, лыжи, туризм |
| Настроение | радость, романтика, спокойствие |

#### 3.2.3 Геолокация

- Извлечение GPS-координат из EXIF
- Обратное геокодирование: страна → регион → город → район
- Для фото без GPS — определение локации по визуальному контенту (опционально, с пометкой «примерно»)
- Отображение на карте

#### 3.2.4 Технические метаданные (EXIF/XMP)

Автоматическое извлечение и индексация:

- Дата и время съёмки (с учётом часового пояса)
- Камера: производитель, модель
- Объектив
- Параметры съёмки: выдержка, диафрагма, ISO, фокусное расстояние
- Режим съёмки, вспышка
- Цветовой профиль, баланс белого
- Разрешение и размер файла
- Для видео: длительность, кодек, битрейт, частота кадров, разрешение, аудиокодек

#### 3.2.5 Визуальный анализ

- Доминирующие цвета (палитра из 5 цветов с процентным соотношением)
- Цветовой тон (тёплый / холодный / нейтральный)
- Ориентация (горизонтальная / вертикальная / квадратная)
- Качество снимка: резкость, экспозиция, шум — для базовой оценки
- Для видео: ключевые кадры, определение сцен

#### 3.2.6 Умные альбомы (автоальбомы)

Система автоматически создаёт альбомы:

- **По событию** — группировка фото, снятых в одном месте в одно время (алгоритм кластеризации по времени и гео)
- **По людям** — отдельный альбом для каждого именованного человека
- **По месту** — по городам и странам
- **По периоду** — «Этот день год назад», «Лето 2025», ежемесячные дайджесты
- **Лучшие снимки** — автоматический выбор лучших фото за период (по оценке качества)

Пользователь может редактировать автоальбомы, переименовывать, скрывать, удалять.

### 3.3 Поиск

#### Полнотекстовый поиск

- По автоматическим тегам
- По пользовательским тегам и описаниям
- По имени файла и названию альбома
- По именам людей

#### Фильтрация

Поисковая строка поддерживает фильтры:

```
person:Мама  tag:море  date:2024-07  camera:Sony  location:Испания
```

Также доступна панель фильтров с чекбоксами и ползунками:

- Период (календарь)
- Люди (мультивыбор)
- Место (карта или список)
- Камера / объектив
- Параметры съёмки (ISO, выдержка, диафрагма — диапазоны)
- Тип файла (фото / видео / RAW)
- Цвет (выбор из палитры)
- Ориентация
- Оценка (звёзды)
- Теги

#### Визуальный поиск

- «Найти похожие» — поиск по визуальной схожести (эмбеддинги изображений)
- Поиск по загруженному изображению («найти похожие на это фото»)
- Поиск по цветовой гамме

### 3.4 Управление доступами

#### 3.4.1 Роли и уровни

Права назначаются на уровне **Пространства**, **Папки**, **Альбома** и **Файла**.

| Роль | Просмотр | Скачивание | Загрузка | Редактирование тегов | Управление структурой | Управление доступами |
|---|:---:|:---:|:---:|:---:|:---:|:---:|
| Владелец | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| Администратор | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ (кроме владельца) |
| Редактор | ✓ | ✓ | ✓ | ✓ | ✓ | — |
| Участник | ✓ | ✓ | ✓ | ✓ | — | — |
| Просмотр + скачивание | ✓ | ✓ | — | — | — | — |
| Только просмотр | ✓ | — | — | — | — | — |

#### 3.4.2 Наследование прав

- По умолчанию вложенные папки наследуют права родительской
- Можно переопределить права для конкретной папки / файла
- Запрет может быть явным (блокирует наследованное разрешение)
- Матрица прав отображается визуально для каждого объекта

#### 3.4.3 Способы предоставления доступа

**Для зарегистрированных пользователей:**
- Приглашение по email
- Поиск по username внутри платформы
- Групповые роли (создание группы пользователей с общими правами)

**Публичные ссылки:**
- Генерация ссылки с заданной ролью
- Опциональный пароль на ссылку
- Срок действия ссылки (без ограничений / конкретная дата / одноразовая)
- Ограничение на количество переходов
- Возможность отозвать ссылку
- Запрет репостинга (отключение кнопки «поделиться» для получателя)

**Временный доступ:**
- Доступ с конкретной даты по конкретную дату
- Автоматическое уведомление за X дней до истечения
- Автоматическое уведомление при истечении

#### 3.4.4 Ограничения для получателей

Дополнительные ограничения поверх роли:

- Запрет скачивания (только онлайн-просмотр)
- Запрет скачивания оригиналов (только превью)
- Водяной знак на скачиваемых файлах (текст или логотип)
- Запрет скачивания RAW-файлов
- Ограничение просмотра по IP-диапазону

#### 3.4.5 Аудит доступов

- Лог всех действий: просмотр, скачивание, загрузка, изменение прав
- Фильтрация лога по пользователю, дате, типу действия
- Экспорт лога в CSV
- Уведомление владельца о нетипичной активности (массовое скачивание)

### 3.5 Совместная работа

- **Комментарии** к файлу и к конкретной области на фото (пин-комментарии)
- **Теги** — совместное редактирование тегов участниками с ролью Участник и выше
- **Избранное** — каждый пользователь ведёт свой список избранного внутри общего пространства
- **Оценки** — звёздочки (1–5), видны всем участникам, агрегируются
- **История версий** для видео и RAW: хранение предыдущих версий файла при перезагрузке
- **Уведомления** о действиях в общих папках (настраивается)

### 3.6 Просмотр и работа с медиафайлами

#### Галерея

- Режимы отображения: сетка (3 размера ячейки), список, временная шкала
- Группировка: по дате, по месту, по событию, по людям
- Сортировка: дата съёмки, дата загрузки, имя файла, размер, оценка
- Бесконечная прокрутка с виртуализацией (производительность при > 100 000 файлов)
- Выделение нескольких файлов (shift+click, ctrl+click, выделение прямоугольником)
- Контекстное меню с быстрыми действиями

#### Просмотрщик файлов

- Полноэкранный режим
- Навигация стрелками / свайпом
- Зум (колесо мыши / жест pinch)
- Панель метаданных (EXIF, теги, люди, местоположение, история)
- Для видео: плеер с управлением скоростью (0.5×, 1×, 1.5×, 2×), субтитры (если есть)
- Слайд-шоу с настройкой скорости и переходов

#### Базовые инструменты

Встроенный неразрушающий редактор (результат сохраняется как отдельная версия):

- Кадрирование и поворот
- Яркость, контраст, насыщенность, температура
- Авто-коррекция
- Применение фильтров

## 4. Нефункциональные требования

### 4.1 Производительность

- Открытие галереи (первый экран): < 1.5 с при > 100 000 файлов
- Загрузка превью при прокрутке: < 300 мс
- Поиск: результаты < 500 мс
- Видеоплеер: старт воспроизведения < 2 с (адаптивный стриминг HLS/DASH)
- API: p95 < 200 мс для чтения, < 500 мс для записи

### 4.2 Масштабируемость

- До 10 млн пользователей
- До 1 млрд файлов в системе
- Горизонтальное масштабирование всех компонентов
- Очередь обработки: до 1 млн задач индексации в час

### 4.3 Надёжность

- Uptime: 99.9% (< 8.7 ч простоя в год)
- Хранение данных: 3 копии в разных зонах доступности
- RPO (целевая точка восстановления): 1 час
- RTO (целевое время восстановления): 4 часа
- Ежедневные резервные копии метаданных, хранение 30 дней

### 4.4 Безопасность

- Шифрование данных в покое: AES-256
- Шифрование в транзите: TLS 1.3
- Аутентификация: email+пароль, OAuth 2.0 (Google, Apple, VK), SAML 2.0 (Enterprise)
- 2FA: TOTP, SMS, email-код
- Сессии: refresh-токены с ротацией, ревокация всех сессий

### 4.5 Совместимость

**Браузеры:** Chrome 110+, Firefox 110+, Safari 16+, Edge 110+  
**Мобильные приложения:** iOS 15+, Android 10+  
**Десктопный клиент:** Windows 10+, macOS 12+  

### 4.6 Локализация и доступность

- Интерфейс: русский, английский (с возможностью расширения)
- Соответствие WCAG 2.1 AA
- GDPR / 152-ФЗ совместимость

## 5. Архитектура системы

### 5.1 Высокоуровневая схема

```
Клиенты (Web / iOS / Android / Desktop)
        │
        ▼
   API Gateway (Rate limiting, Auth)
        │
   ┌────┴────────────────────────────┐
   │                                 │
   ▼                                 ▼
Основной API                  Media API
(метаданные, права,           (upload, streaming,
поиск, пользователи)          transcoding)
   │                                 │
   ▼                                 ▼
PostgreSQL                    Object Storage
(метаданные, ACL)             (S3-совместимое)
Redis (кэш)                          │
Elasticsearch (поиск)                ▼
                              CDN (превью, стриминг)

──────────────────────────────────────
Async Workers (очередь задач)
  - ML-индексация (лица, объекты, сцены)
  - Генерация превью и транскодирование
  - Геокодирование
  - Автоальбомы
  - Уведомления
```

### 5.2 ML-компоненты

| Компонент | Задача | Технология |
|---|---|---|
| Face Detection | Обнаружение лиц | RetinaFace / MediaPipe |
| Face Recognition | Идентификация людей | ArcFace / FaceNet |
| Object Detection | Объекты и сцены | YOLOv8 / CLIP |
| Image Embedding | Визуальный поиск | CLIP / DINOv2 |
| Quality Assessment | Оценка качества фото | NIMA / BRISQUE |
| Geo Visual | Определение места по фото | GeoEstimation |

## 7. Интеграции

### 7.1 Обязательные

| Интеграция | Назначение |
|---|---|
| S3-совместимое хранилище | Хранение оригиналов и превью |
| CDN (CloudFront / Fastly) | Раздача медиаконтента |
| Email-провайдер (SES / SendGrid) | Транзакционные письма |
| Push-уведомления (FCM / APNs) | Мобильные уведомления |
| Maps API | Обратное геокодирование, карта |
| OAuth (Google, Apple) | Вход через соцсети |

## 8. Безопасность

### 8.1 Защита данных

- Все файлы хранятся с серверным шифрованием (SSE-S3 или SSE-KMS)
- URL для доступа к файлам — presigned (срок действия 1 час для приватных файлов)
- Никакой прямой адресации по пути файла в хранилище

### 8.2 Защита от злоупотреблений

- Rate limiting на всех эндпоинтах API
- Ограничение скорости скачивания для бесплатных аккаунтов
- Детектирование массового скачивания и уведомление владельца
- CAPTCHA при подозрительной активности
- Сканирование загружаемых файлов на известный CSAM (PhotoDNA)

### 8.3 GDPR / 152-ФЗ

- Явное согласие на обработку биометрических данных (лица) — отдельный чекбокс
- Возможность полного удаления аккаунта и всех данных (включая лица) в течение 30 дней
- Экспорт всех своих данных (файлы + метаданные)
- Возможность отключить все виды ML-анализа
- Хранение данных российских пользователей на серверах в РФ (опция)

### 9.1 Продуктовые метрики

## 11. Открытые вопросы

Следующие вопросы требуют принятия решений перед началом разработки:

1. **Модель монетизации** — freemium (сколько ГБ бесплатно?), подписка (тарифы?), B2B-план?
2. **Клиентское шифрование (E2E)** — шифровать ли файлы на стороне клиента до загрузки? Это исключит серверный ML-анализ.
3. **On-premise версия** — нужна ли для корпоративных клиентов?
4. **Видеотранскодирование** — в какие форматы и разрешения конвертировать видео при загрузке?
5. **Лимиты бесплатного плана** — хранилище, количество файлов, ограничения на ML?
6. **Регионы хранения** — какие дата-центры, есть ли требование хранить данные в РФ?
7. **Обработка CSAM** — обязателен ли PhotoDNA или достаточно hash-matching?
8. **Приоритет мобильного приложения** — нативное (Swift/Kotlin) или React Native / Flutter?
